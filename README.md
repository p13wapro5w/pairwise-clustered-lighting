# pairwise-clustered-lighting

夜战场景一开火，墙面亮斑忽大忽小，远处灯泡在墙上投出方块状光斑，切到分屏后左屏的灯又跑到右屏：光照分簇的网格分辨率按屏幕宽高写死，超宽屏和 FOV 变化后簇边界错位；深度切片用线性划分，近处几厘米挤了十几层、远处几百米只有一层；球形光和聚光灯都用同一个包围盒，锥形光把身后墙面也算进去；每簇光源上限固定，超出后直接丢弃最远的灯，主灯在近处反而被砍；透明物体只取不透明 pass 的簇索引，玻璃后面的灯全丢；计算着色器和前向渲染共用一张簇缓冲，异步队列没插屏障；多相机各自建簇却共用同一块 UAV，分屏互相覆盖；带阴影的灯在簇里算了两次，亮度翻倍；光源边界在相机后方的簇里产生 NaN，整块像素变黑；相机快速平移时簇缓冲延迟一帧，墙上的光斑拖在身后；点光源衰减用 1/d²，近处数值溢出成白斑；分簇构建按 16×16 像素，4K 下缓冲爆掉后静默截断。render/clustered_lighting.py 是核心，tests/test_clustered_lighting.py 15个红。要修的是：网格随宽高比；对数深度切片；光锥包围；溢出策略；透明簇索引；异步屏障；多相机隔离；重复计数；NaN 防护；缓冲延迟；衰减稳定；分辨率预算。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。

子方向：图形渲染；任务类型：Bugfix；语言/框架：Python 3, pytest；环境可复现等级：无外部依赖。
